# BRS Quotation Center

ระบบออกใบเสนอราคาออนไลน์ของบริษัทบุญรอด ซัพพลายเชน จำกัด

- **หน้าเว็บ:** อยู่บน GitHub Pages เปิดได้จากคอมและมือถือ
- **ทะเบียนเลขที่:** ไฟล์ `Run ใบเสนอราคา SCO.xlsx` ของทีม SCO-Finance (Sheet1) ระบบอ่านเลขล่าสุดแล้ว +1 รูปแบบ `Q/SCO/ปีเลข3หลัก` เช่น Q/SCO/2026021
- **ข้อมูลใบเสนอราคาแบบเต็ม:** ไฟล์ `Quotation Center Data.xlsx` ใน OneDrive โฟลเดอร์ `BRS Quotation Center` (ชีต Quotes 1 แถวต่อ 1 ใบ, ชีต Settings)
- **เอกสารที่เซ็นแล้ว:** OneDrive โฟลเดอร์ `BRS Quotation Center/เอกสารที่เซ็นแล้ว` เปิดดูได้เฉพาะคนในบริษัท
- **ตัวกลาง:** Power Automate flow ชื่อ **BRS Quotation Center API** (HTTP trigger) เรียก Office Scripts 2 ตัว
  - `Script 2` ในไฟล์ Run: ออกเลข ตรวจเลขซ้ำ และเขียนแถว เลขที่ | เรื่อง (รายการแรก) | วันที่ | ผู้ดำเนินการ | ลูกค้า
  - `Script 1` ในไฟล์ Data: เก็บ/อ่านข้อมูลใบเสนอราคา ยกเลิกใบ และผูกไฟล์ที่เซ็นแล้ว

## ไฟล์ใน repo นี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด |
| `config.js` | ที่อยู่ HTTP ของ Flow ใน Power Automate |
| `Code.gs` | ระบบเดิมบน Google Apps Script (เลิกใช้แล้ว เก็บไว้อ้างอิง) |

## ข้อควรรู้

- แต่ละคำสั่ง (เปิดหน้า บันทึก แนบไฟล์) ใช้เวลาประมาณ 8–15 วินาที เพราะ Power Automate ต้องเปิดไฟล์ Excel ทั้ง 2 ไฟล์
- หน้าเว็บดึงข้อมูลใหม่ทุก 5 นาที และทุกครั้งที่กลับมาที่แท็บ เพื่อไม่ให้ใช้จำนวนรันของ Power Automate มากเกินไป
- ห้ามแก้คอลัมน์ `data (ห้ามแก้)` ในไฟล์ Data ด้วยมือ และห้ามเปลี่ยนชื่อ/ย้ายไฟล์ทั้ง 2 ไฟล์ ถ้าย้ายต้องแก้ path ใน Flow
- ไฟล์แนบใหญ่ได้ไม่เกิน 15 MB ต่อไฟล์ (PDF, JPG, PNG)
- Flow ทำงานด้วยบัญชี napong_a@brs-group.com ถ้าบัญชีนี้ถูกปิดหรือเปลี่ยนรหัสผ่าน ต้องเข้าไปเชื่อม connection ใน Flow ใหม่
- ที่อยู่ใน `config.js` เป็นเหมือนกุญแจ ใครมีที่อยู่นี้ก็เรียก Flow ได้ ถ้าต้องการเปลี่ยน ให้สร้าง URL ใหม่ใน Flow แล้วแก้ไฟล์นี้

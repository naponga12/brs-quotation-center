# BRS Quotation Center

ระบบออกใบเสนอราคาออนไลน์ของบริษัทบุญรอด ซัพพลายเชน จำกัด

- **หน้าเว็บ:** อยู่บน GitHub Pages เปิดได้จากคอมและมือถือ ไม่ต้องลงชื่อเข้าใช้
- **ข้อมูลใบเสนอราคา:** เก็บใน Google Sheets หนึ่งแถวต่อหนึ่งใบ
- **เอกสารที่เซ็นแล้ว:** เก็บใน Google Drive แยกโฟลเดอร์ตามเลขที่ใบเสนอราคา
- **ตัวกลาง:** Google Apps Script รับคำสั่งจากหน้าเว็บ และออกเลขที่เอกสารโดยไม่ให้ซ้ำกัน

## ไฟล์ใน repo นี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด |
| `config.js` | ที่อยู่ของ Google Apps Script (แก้ไฟล์นี้ไฟล์เดียวเมื่อเปลี่ยนที่เก็บข้อมูล) |
| `Code.gs` | โค้ดที่ต้องนำไปวางใน Google Apps Script (ไม่ได้ใช้บน GitHub) |

## ส่วนที่ 1: ตั้งค่า Google Sheets และ Google Drive (ทำครั้งเดียว ประมาณ 10 นาที)

1. เข้า <https://sheets.google.com> ด้วยบัญชี Gmail ที่จะใช้เก็บข้อมูล แล้วสร้างสเปรดชีตเปล่า ตั้งชื่อว่า **BRS Quotation Center**
2. ที่เมนูด้านบน กด **ส่วนขยาย (Extensions) > Apps Script**
3. ในหน้า Apps Script ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้ววางโค้ดจากไฟล์ `Code.gs` ใน repo นี้ลงไปทั้งไฟล์ จากนั้นกดรูปแผ่นดิสก์เพื่อบันทึก
4. ที่แถบด้านบน เลือกฟังก์ชัน **importOldData** แล้วกด **Run (เรียกใช้)**
   - Google จะขออนุญาต ให้กด **Review permissions** แล้วเลือกบัญชี Gmail ของคุณ
   - ถ้าขึ้นหน้า "Google hasn't verified this app" ให้กด **Advanced** แล้วกด **Go to … (unsafe)** จากนั้นกด **Allow**
     หน้านี้ขึ้นเพราะเป็นสคริปต์ที่คุณติดตั้งเองในบัญชีของคุณ ไม่ใช่แอปที่เผยแพร่สาธารณะ
   - เมื่อรันเสร็จ ในสเปรดชีตจะมีชีต **Quotes**, **Numbers** และ **Settings** พร้อมใบเสนอราคาเดิม 2 ใบ (Q-SCO-2026012 และ Q-SCO-2026013) และใน Google Drive จะมีโฟลเดอร์ **BRS Quotation Center - เอกสารที่เซ็นแล้ว**
5. กด **Deploy (การทำให้ใช้งานได้) > New deployment (การทำให้ใช้งานได้รายการใหม่)**
   - กดรูปเฟือง แล้วเลือก **Web app**
   - **Execute as:** Me (บัญชีของคุณ)
   - **Who has access:** Anyone (ทุกคน)
   - กด **Deploy**
6. คัดลอก **Web app URL** ที่ได้ (ขึ้นต้นด้วย `https://script.google.com/macros/s/` และลงท้ายด้วย `/exec`)
7. นำ URL ไปใส่ในไฟล์ `config.js` ระหว่างเครื่องหมายคำพูด หรือส่ง URL ให้ Claude ใส่ให้

ทดสอบ: เปิด Web app URL ในเบราว์เซอร์ ถ้าขึ้นข้อความ `"ระบบพร้อมใช้งาน"` แปลว่าติดตั้งถูกต้อง

## ส่วนที่ 2: เปิดหน้าเว็บด้วย GitHub Pages

1. ใน repo นี้บน GitHub กด **Settings > Pages**
2. ที่ **Source** เลือก **Deploy from a branch**
3. ที่ **Branch** เลือก **main** และโฟลเดอร์ **/ (root)** แล้วกด **Save**
4. รอ 1-2 นาที หน้าเดิมจะขึ้นลิงก์ของเว็บ เช่น `https://ชื่อบัญชี.github.io/ชื่อ-repo/`
5. ส่งลิงก์นี้ให้ทีมขาย เปิดใช้ได้ทันที

## การใช้งานประจำวัน

- **สร้างใบเสนอราคา:** กด "สร้างใบเสนอราคา" ระบบใส่เลขที่ถัดไปให้เอง กรอกข้อมูล แล้วกด "บันทึก"
- **ดาวน์โหลด:** กดปุ่ม Excel หรือ PDF ในหน้าแก้ไข หรือในหน้ารายการ
- **แนบเอกสารที่เซ็นครบแล้ว:** เปิดใบที่บันทึกแล้ว กด "แนบไฟล์" ได้ทั้ง PDF และรูป JPG/PNG ไฟล์ละไม่เกิน 20 MB
- **ลบ:** ใบที่ลบจะยังอยู่ในรายการเป็นแถบสีทึบพร้อมตรา "ยกเลิก" และไม่นับในยอดรวม
- **ข้อมูลอัปเดต:** หน้าเว็บโหลดข้อมูลใหม่ทุก 1 นาที และทุกครั้งที่กลับมาเปิดหน้านี้

## เลขที่เอกสาร

- รูปแบบ: `Q-SCO-` + ปี ค.ศ. ของวันที่ในเอกสาร + ลำดับ 3 หลัก เช่น Q-SCO-2026014
- ปีใหม่เริ่มนับใหม่ที่ 001 เช่น Q-SCO-2027001
- ถ้าสองคนบันทึกพร้อมกัน ระบบให้เลขทีละคน ไม่มีทางได้เลขซ้ำ
- เลขที่เคยออกไปแล้วจะไม่ถูกนำกลับมาใช้ แม้ใบนั้นจะถูกลบ (ดูรายการได้ในชีต **Numbers**)

## ข้อควรรู้

- **ห้ามแก้ข้อมูลในชีตด้วยมือ** ให้แก้ผ่านหน้าเว็บเท่านั้น ข้อมูลจริงอยู่ในคอลัมน์ "data (ห้ามแก้)" ส่วนคอลัมน์อื่นมีไว้ให้อ่านง่าย
- **ใครมีลิงก์เว็บก็เปิดดูและแก้ไขได้** เพราะระบบไม่มีรหัสผ่าน และ repo บน GitHub แบบฟรีเป็นสาธารณะ ใครเห็นไฟล์ `config.js` ก็เข้าถึงข้อมูลได้ ถ้าต้องการรหัสทีมในภายหลัง ให้ Claude เพิ่มให้ได้
- **ไฟล์ที่แนบ** ถูกตั้งเป็น "ทุกคนที่มีลิงก์ดูได้" เพื่อให้ทีมเปิดได้โดยไม่ต้องขอสิทธิ์
- **สำรองข้อมูล:** ใน Google Sheets กด ไฟล์ > ทำสำเนา เป็นครั้งคราว

## เมื่อแก้โค้ด Apps Script ภายหลัง

วางโค้ดใหม่แล้วบันทึก จากนั้นกด **Deploy > Manage deployments** กดรูปดินสอ เลือก **Version: New version** แล้วกด **Deploy**
วิธีนี้ URL เดิมยังใช้ได้ ไม่ต้องแก้ `config.js`

## ย้ายที่เก็บข้อมูลไปบัญชี Google อื่น

ทำส่วนที่ 1 ใหม่ในบัญชีใหม่ แล้วคัดลอกแถวในชีต Quotes, Numbers และ Settings จากสเปรดชีตเดิมไปวาง จากนั้นแก้ `config.js` ให้เป็น Web app URL ใหม่
